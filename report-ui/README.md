# Report UI

Простой React интерфейс для системы генерации отчетов, который удовлетворяет требованиям User Story из презентации.

## Функциональность

- Выбор диапазона дат (01.01.2024 - 31.01.2024)
- Выбор типа отчета "Активность пользователей"
- Кнопка "Сгенерировать отчет"
- Отображение статуса "В обработке" с временем ожидания
- Асинхронная обработка (до 15 минут)
- Таблица результатов с пагинацией
- Скачивание отчета в CSV формате
- Возможность отмены генерации

## Установка и запуск

1. Установите зависимости:
```bash
cd report-ui
npm install
```

2. Запустите приложение:
```bash
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

## API Endpoints

UI ожидает следующие endpoints от backend:

- `POST /api/admin/reports` - создание отчета
- `GET /api/admin/reports/{reportId}` - получение статуса и результатов
- `DELETE /api/admin/reports/{reportId}` - отмена отчета
- `GET /api/admin/reports/{reportId}/download` - скачивание CSV
